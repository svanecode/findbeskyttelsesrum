# Historisk cutover-arkiv

Dokumenterne i denne mappe er planlægnings-, audit- og statusbilleder fra overgangen til den nuværende `app_v2`-løsning. De bevares som beslutningsspor og kan derfor med vilje beskrive gamle risici, legacy-dataflows eller arbejde, der siden er afsluttet.

De er ikke aktuelle driftsvejledninger. Brug i stedet:

- [projektets README](../../../README.md) til lokal udvikling, release og drift;
- [dokumentationsoversigten](../../README.md) til aktive data- og QA-aftaler;
- de faktiske filer i `supabase/migrations` og `.github/workflows` til migrations- og automatiseringsadfærd.
